# ORBIT Team Website

A simple, cinematic one-page website for Team ORBIT.

## Included
- Your supplied ORBIT logo
- Responsive design for desktop and mobile
- Animated orbital rings and stars
- Scroll reveal animations
- Mouse-follow glow
- Mouse parallax
- About / Work / Team / Contact sections
- No framework required

## How to use
1. Open `index.html` in a browser.
2. Replace the placeholder project names/descriptions.
3. Replace the placeholder team members and roles.
4. Change `hello@orbit.team` to your real contact email.
5. If you want to publish it, upload the whole folder to GitHub Pages, Netlify, Vercel, or your hosting provider.

## Main files
- `index.html` — page content
- `style.css` — design and animations
- `script.js` — interactive animations
- `assets/orbit-logo.jpg` — your logo
